AMSpiriT Lite — Quick Reference

AMSpiriT Lite is a Linux/Windows Amstrad CPC emulator based on the AMSpiriT core by David MANUEL.

Drag and drop a file onto the emulator window to load it. The Qt frontend also has a File menu to open a file dialog.

Tip: hold Ctrl while dropping a file to perform a hard reset before loading — useful for starting a disk image in a clean machine state.

Snapshot Slots

AMSpiriT Lite maintains 4 quick-save slots (1–4) per game. Slots are stored alongside the ROM/disk image and persist across sessions.

ActionKey / Button
Quick-save to current slotF4
Quick-load from current slotShift+F4
Cycle to next slot (while paused)Gamepad Start / + button
Cycle to previous slot (while paused)Gamepad Select / − button
Save to slot (while running)Gamepad Start / + button
Load from slot (while running)Gamepad Select / − button

In the Qt frontend, snapshot slots are also accessible from the Emulation → Snapshots menu.

Rewind

The optional rewind feature records a rolling buffer of CPC state snapshots in RAM as the emulator runs. When paused, you can step backwards and forwards through the recorded history — useful for debugging, finding the right moment to screenshot, or just rewinding a bad move in a game.

Enable rewind at startup with --enable-rewind. In the Qt frontend, use the Emulation → Rewind menu to enable it and adjust settings.

Key / ActionDescription
← (when paused)Step one frame backward in the rewind history
→ (when paused)Step one frame forward (toward present), or step one normal frame if fully caught up
D-pad ← (gamepad, when paused)Step backward in rewind
D-pad → (gamepad, when paused)Step forward in rewind / resume if at head

The status bar / title shows < N / M while rewound (N frames ahead of oldest, M total stored).

Memory: each snapshot is approximately 1.6 MB. The default buffer holds 100 snapshots (~160 MB); adjust with --rewind-slots N.

Turbo Mode

Turbo mode disables 50 Hz pacing and mutes audio, letting the emulator run at the host CPU's full speed. Useful for skipping long tape loads or intros.

  • Press Shift+F9 to toggle turbo on or off at any time.
  • When launched with --turbo together with --autotype or -A, turbo stops automatically once the auto-typing sequence finishes.

Gamepad / Joystick

The Qt frontend uses the SDL2 GameController API (XInput on Windows, evdev on Linux, GameController on macOS). The SDL frontend uses the legacy joystick API. Both detect controllers at startup and on hot-plug; the first controller found maps to CPC joystick port 1.

Web Debug Server

The emulator embeds an HTTP debug server (on by default, bound to 127.0.0.1:6128) that exposes a full web interface in the browser: Z80 registers, Gate Array, PSG, FDC, memory heat map, ASIC, disk, config, scripting, and more.

amspirit-lite-sdl [--no-web-server] [--web-addr 0.0.0.0] [--web-port 6128] [--web-html path/to/ui.html]
OptionDescription
--web-serverEnable the server (on by default)
--no-web-serverDisable the server
--web-addr <address>Bind address (default: 127.0.0.1 — local only; use 0.0.0.0 for all interfaces)
--web-port <port>Listening port (default: 6128)
--web-html <file>Path to the HTML UI file (default: amspirit-lite.html next to the binary)
--lua-full-stdlibLet scripts POSTed to the web API use the full Lua stdlib (io, os.execute, package, debug). Off by default — such scripts are sandboxed to a jailed fs.* file table. Any page open in your browser can reach the API, so only enable this on a machine you trust.
The amspirit-lite.html file can be edited without recompiling. If the file is missing, the UI embedded in the binary is used as a fallback.

The interface is organised into tabs: Keyboard, BASIC, Debug (Z80/disassembly/breakpoints), ROMs (ROM Map), Audio, Heat Map (memory), ASIC, Poke, Script, Config, Disk, and Settings.

BASIC Editor

The BASIC tab works with Locomotive BASIC programs:

  • Paste or upload Locomotive BASIC source code
  • Inject: tokenizes and writes the program directly into CPC RAM at address 0x0170
  • Export: reads and detokenizes the current BASIC program from RAM
  • Parameters: ?reset=1 (hard reset first), ?run=1 (auto-type RUN after inject)
  • Maximum size: ~44 KB per CPC model

Keyboard Mapping

The Keyboard tab displays the current keyboard layout and all mapped keys (read-only reference for debugging keyboard input issues).

ROM Map

The ROMs tab shows the current ROM catalog: which firmware, extension ROM (R<n>:) and cartridge bank is loaded in each slot, and where it came from. It has a compact view and a per-slot view.

Snapshot slots are not managed from the web interface — use F4 / Shift+F4, or the Qt Emulation → Snapshots menu.

Keymap Configuration (keymap.cfg)

Generate a keymap file using the --dump-keymap option, then edit it to your preferences and restart the emulator:

amspirit-lite-sdl --dump-keymap=keymap.cfg

(With no filename, --dump-keymap writes keymap-sdl.cfg in the current directory.)

Place the generated keymap.cfg in your ROMs/ or config/ directory (or point --keymap at it directly). The file uses INI format with two sections: [keyboard layout] and [emulator hotkeys].

Supported hotkey actions: PAUSE, MUTE, HELP, SCREENSHOT, SNAPSHOT_SAVE, SNAPSHOT_LOAD, VOLUME_UP, VOLUME_DOWN, TURBO, HARD_RESET, SOFT_RESET, FULLSCREEN, FULL_FRAME, CYCLE_SCREEN, CYCLE_DEBUG_SCREEN, TOGGLE_OVERLAY, CYCLE_CRTC, CYCLE_MONITOR, FRAME_STEP, DEBUG_STEP, DEBUG_STEP_OVER, DEBUG_RESUME, DEBUG_STEP_BACK, DEBUG_CLEAR_BREAKPOINTS, OPEN_FILE, QUIT

Key format: Single key (F1, A, Escape, Return, Space) or modifiers (Ctrl+X, Shift+F1, Alt+Shift+P). Case-insensitive.

Changes take effect on next restart. To find a key's code, run with -K flag and watch for DOWN messages in the console. Note: SDL and Qt applications use different key codes; use separate keymap files for each if you run both.
